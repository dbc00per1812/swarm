What Swarm does

Swarm gives agents selected tools for GitHub pull requests, Slack message search, Linear issues, and Gmail search.

You choose the connected accounts and enabled tools. You can also share selected tools with organization members.

Swarm stores service credentials on its server. It sends tool results to the requesting agent.

GitHub provides Swarm account sign-in. Google authorization connects Gmail separately.

Gmail is currently available only to approved Google test users. Read about Gmail data use and access removal.

Connect Gmail to Swarm

Google grants Swarm read access to Gmail messages and settings. The current search tool does not fetch message bodies or attachments.

Swarm sends search queries to Google. It sends message IDs, thread IDs, and the Subject, From, and Date headers to your requesting agent.

Swarm stores encrypted access and refresh tokens and your Gmail address. If you share the tool, organization members' agents can request mailbox searches.

Each search requires approval on the Swarm website. Use an agent whose settings meet Google's data-use rules.

Gmail is currently limited to approved Google test users. Test access can expire after seven days.
